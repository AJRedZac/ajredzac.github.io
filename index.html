A desktop application for self-service kiosks at intercity bus terminals, where travelers buy tickets without an agent. The interesting part was never the UI: a Java 21 and JavaFX kiosk application integrating a proprietary native payment SDK, Windows thermal printing, native printer-status monitoring and REST backend services.
